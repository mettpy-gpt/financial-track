# เว็บบันทึกรายรับรายจ่าย

เว็บไซต์ static พร้อมเผยแพร่ด้วย GitHub Pages โดยใช้ไฟล์ `index.html` ไฟล์เดียว ไม่ต้องติดตั้ง build tools

## ข้อจำกัดข้อมูล

รายการ งบประมาณ และหมวดหมู่ที่เพิ่มจะจัดเก็บใน `localStorage` ของเบราว์เซอร์และอุปกรณ์ที่ใช้งาน ข้อมูลไม่ซิงก์ระหว่างมือถือกับคอมพิวเตอร์ และการล้างข้อมูลเว็บไซต์/เปลี่ยนเบราว์เซอร์อาจทำให้ข้อมูลหาย ควรส่งออก CSV หรือใช้เมนูสำรองข้อมูลเป็นระยะ

## เผยแพร่ผ่าน GitHub Pages

1. สร้าง repository ใหม่ชื่อ `finance-tracker` (หรือชื่ออื่น) ในบัญชี GitHub
2. ตั้ง Public หากต้องการให้ทุกคนเปิดเว็บได้จากลิงก์ Pages; โค้ดและไฟล์ใน repo จะมองเห็นสาธารณะ
3. อัปโหลด `index.html` และ `README.md` ไปที่รากของ repository แล้ว commit
4. ไปที่ **Settings → Pages**
5. ใน **Build and deployment** เลือก **Deploy from a branch**, เลือก branch `main` และโฟลเดอร์ `/(root)` แล้วกด **Save**
6. รอให้ GitHub Pages ทำงาน จากนั้นเปิดลิงก์ที่แสดงในหน้า Pages (รูปแบบ `https://mettpy-gpt.github.io/finance-tracker/`)

ก่อนเผยแพร่ ควรทดสอบรายการตัวอย่างและลบข้อมูลตัวอย่าง หากมีข้อมูลส่วนตัวในไฟล์/ประวัติ Git ห้ามอัปโหลด
